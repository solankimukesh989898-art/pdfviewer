# FAQ

## What is PDF Viewer?
PDF Viewer is a lightweight application designed to allow users to view PDF files with ease.

## How do I install PDF Viewer?
You can install PDF Viewer by downloading it from our [Releases page](https://github.com/solankimukesh989898-art/pdfviewer/releases).

## What platforms does PDF Viewer support?
PDF Viewer is available for Windows, macOS, and Linux.

## How can I report a bug?
If you encounter any issues, please raise an issue on our [GitHub Issues page](https://github.com/solankimukesh989898-art/pdfviewer/issues).
