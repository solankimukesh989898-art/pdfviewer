# 👋 Welcome to LiteDoc Viewer

A lightweight and efficient PDF viewer application designed for fast, offline document viewing and manipulation.

## ✨ Features

- 📄 **Offline PDF Viewing** - Works completely offline, no internet required
- ⚡ **Fast Performance** - Optimized for quick loading and smooth scrolling
- 🔒 **User Privacy** - No account required, all processing happens locally on your device
- 💾 **Minimal Resources** - Lightweight app that doesn't consume much storage
- 🎨 **Easy to Use** - Intuitive interface for quick document access

## 📱 About the App

LiteDoc Viewer is a mobile application built for users who value:
- **Privacy** - Your documents never leave your device
- **Speed** - Fast loading and navigation
- **Simplicity** - Easy-to-use interface
- **Reliability** - Stable offline functionality

## 🚀 Getting Started

Download LiteDoc Viewer from your app store and start viewing PDFs instantly. No registration required!
